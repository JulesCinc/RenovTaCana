Carte interactive

Visualisez le réseau, filtrez par criticité et préparez votre plan de travaux.

Vue d'ensemble

Carte

Chaque trait est une canalisation, colorée selon sa criticité. Survolez pour l'infobulle, zoomez et déplacez-vous librement.

Légende

Le panneau en bas à gauche rappelle l'échelle : critique (rouge), attention (orange), bon état (vert), non évalué (gris).

Recherche et filtres

Recherche d'adresse

Tapez une adresse puis validez. La carte centre les résultats trouvées ; sinon vous êtes redirigé vers le tableau des adresses.

Filtres criticité

Tous affiche l'ensemble du réseau. Cliquez sur une catégorie pour ne garder que celle-ci, puis combinez plusieurs boutons (ex. Critique + Attention).

Tous Critique Attention

Sélection

Hors mode Zone

  • Clic sur une canalisation : l'ajoute ou la retire de la sélection (trait vert).
  • Double-clic : ouvre la fiche adresse détaillée.
  • Échap ou clic dans le vide : efface toute la sélection.

Outil Zone

Activez le bouton Zone dans la barre d'outils. La sélection par rectangle ne concerne que les canalisations visibles selon vos filtres actifs.

Rectangle seul

Remplace la sélection par les canalisations du rectangle.

Ctrl
+ rectangle

Ajoute les canalisations du rectangle à la sélection existante.

Alt
+ rectangle

Retire du sélection les canalisations du rectangle (aperçu rouge).

Clic simple

Dans le vide, sans glisser : efface la sélection.

Le panneau « zone » résume le rectangle ; le lien mène au tableau filtré sur la même sélection.

Plan de travaux et chantiers

Plan de travaux

Une fois des canalisations sélectionnées, le bouton fixe en bas de carte les envoie vers le plan de travaux. Le badge dans l'en-tête indique le nombre déjà dans le plan.

Chantiers

Superpose les zones de chantier sur la carte. Recliquez pour masquer l'overlay.
