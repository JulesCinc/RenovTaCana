# RenovTaCana

Ce dépôt présente la **version V1.0** du projet **RenovTaCana**, porté par l’entreprise **Eau d’Azur**.

Cette livraison est **volontairement très limitée** : elle fixe un premier périmètre fonctionnel et technique minimal. Elle sert de **socle** — base de code et de données — sur laquelle les versions suivantes du projet vont s’appuyer et s’étendre.
